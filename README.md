# Clickmaster

Clickmaster — футбольный кликер для школьников. Отвечай на вопросы по ивриту, математике, английскому и логике, зарабатывай секунды и забивай голы кликами. Побей рекорд друзей!

Вся игра — один файл `index.html`. Слова и задачи лежат в начале скрипта, в списках `WORDS` и `LOGIC`: их можно менять и дополнять.
